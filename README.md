# FinanCont — Dashboard

Protótipo acadêmico de dashboard de gestão financeira com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia a pasta `financont`.
2. Abra `src/pages/dashboard.html` no navegador.
3. O gráfico é desenhado com Canvas nativo; não há bibliotecas externas nem etapa de build.

## Arquivos
- `src/pages/dashboard.html`: estrutura da tela.
- `src/css/dashboard.css`: estilos e responsividade.
- `src/js/dashboard.js`: dados fictícios, filtros, gráfico e interações demonstrativas.

## Observação
Este projeto usa dados fictícios e não possui backend, autenticação real nem persistência de dados.
